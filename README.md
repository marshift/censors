# censors
simple "censor bar" for covering things (or people) you don't like

## usage
* statically-linked binaries are available from [GitHub Actions](//nightly.link/marshift/censors/workflows/build/master)
* on launch, the censor will be very small, and centered to the screen
	- to move it, use the arrow keys
	- to resize it, hold shift and use the arrow keys
	- hold ctrl with the above for increased precision
